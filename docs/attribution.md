# Asset attribution

Every non-code asset in this repository (fonts, images, example art, presets) is listed here with its author, source and license. `cargo xtask assets` (part of `cargo xtask ci`) fails if an asset file is missing from this table.

**Policy (mandatory):** Kition Layout contains **no Adobe iconography, images, artwork, presets, swatch libraries or ICC profiles**. Every asset is original work by Kition Layout contributors or third-party material under an open license (OSI open source, public domain / CC0, or Creative Commons that allows redistribution). Screenshots of Adobe software are never committed. Font files are not added here: shared fonts live in [KitionAI/kition-fonts](https://github.com/KitionAI/kition-fonts), an optional build input (`KITION_FONTS_DIR`, see AGENTS.md).

Generated-in-code art is original and has no file to list: default swatches, and the sample magazine's imagery (`crates/engine/engine/src/sample.rs`).
